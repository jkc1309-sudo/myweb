简介

用产品方法做 AI 系统

我是浙江大学设计学博士生，方向为人机交互。日常工作更接近 AI 产品经理：从业务痛点出发拆解需求，规划可落地的方案，再协同设计、内容与开发把系统做出来，并用实验或线上数据验证效果。

最近三年，我同时推进博物馆智能导览的规模化交付、面向专业用户的 Agent 工作流，以及教育场景里的虚拟学生智能体。关注的不是模型本身，而是它在真实场景里是否可信、可控、可被评估。

需求分析 业务流程拆解 Agent 工作流设计 LLM / RAG 原型与交互设计 实验设计与数据验证 跨团队协作
